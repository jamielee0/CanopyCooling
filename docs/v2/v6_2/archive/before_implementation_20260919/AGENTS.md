## Scope and preservation

Preserve unrelated user changes, raw data and historical result packages. Store active v6.2 documentation in `docs/v2/v6_2/`; keep original sources and archived prior documents with checksums. Do not commit, push, send messages or schedule meetings without the user's explicit request. The current request updates documentation; it does not execute the pilot.

## Scientific rules for subsequent implementation

Estimate one canopy slope per city-pass with block intercepts and native-cell observations. Match cells, covariates, weights and resampling in temperature and emitted-energy models. VPD is descriptive only. No eight-class unmixing. Keep the total time pattern primary and geometry/season standardization secondary.

Set nonthermal support thresholds from observed distributions and record them before fitting. Freeze all effect-dependent decisions, scale tolerance, time model, references and precision aggregation before coefficient access. A failed gate is a result; do not rescue it by selecting passes or rules after seeing outcomes. Full-city processing remains paused until pilot review and a recorded decision.

Keep empirical, estimated and synthetic outputs distinct. Use whole-block spatial resampling for Stage 1 and independent pass/day clusters for time-pattern uncertainty. Never treat dependent pixels as independent temporal observations. Preserve coefficient sealing and prior thermal-access records; publish only permitted precision diagnostics before release.

## Data and verification

Never expose credentials. Preserve input provenance, exact products, QA, acquisition identity and checksums. Audit complete catalogue metadata and unique ground footprints; never double-count tile overlaps or interpolate LST. Verify the current data-link target before execution.

New analysis logic needs meaningful network-free known-answer checks for pooling, spatial ownership, units, support, transformation, bootstrap and sealed outputs. Run checks appropriate to the actual change. Documentation-only work requires cross-document, YAML, checksum and visual checks; it does not require rerunning a retired scientific pipeline.
