# v6.2 scientific output root

Only provenance-complete empirical outputs under the current pooled city-pass protocol belong here. Before the recorded coefficient release, open files may contain support and precision diagnostics only: pass identity, standard errors, bootstrap widths without endpoints, counts, variance, convergence and leverage. Coefficients, predictions, signed contrasts, centered locations and raw bootstrap draws remain sealed.

After the model/settings freeze, precision ruling and recorded review release, the authorized empirical coefficient and time-contrast outputs may be reported here with the release provenance. Full-city scaling still requires pilot review. Synthetic material remains under `tests/fixtures/synthetic_demo/` with SYNTHETIC_DATA labels; historical results remain in their preserved packages. The output-boundary implementation must be checked against these rules before the new pilot runs.
