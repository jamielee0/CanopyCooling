# docs/

Written documentation: design rationale, the reproduction guide, and the result notes.
Tracked in git as markdown.

- **`DESIGN_DECISIONS.md`** — the single authoritative record of *why* the pipeline is built
  the way it is: every methodological choice, by section, with the key numbers. Code modules
  point here instead of repeating the rationale. **Start here when reviewing the methods.**
- `pipeline.md` — end-to-end reproduction guide: the dependency DAG (0→16), each step's command
  and key outputs, the `src/run_all.py` driver usage, the manual touch-points, and how to re-run
  the network-free processing half (9–16) from saved interim.
- `section2_qc01_coverage_audit.md` — the professor-approved `00`+`01` ECOSTRESS
  mandatory-QA decision, strict-`00` before/after counts, the recovered tile and
  downstream sample changes, plus the unchanged quality caveat for class `01`.
- `section11_anomaly_qc_note.md` — Section 11 QC note: the z-score outcomes for VPD, root-zone
  soil moisture (the primary water-supply axis), and NDMI (a vegetation-condition check) —
  whole-record mean/std, the day-of-year-vs-whole-season
  seasonal-cycle-removal proof, and the 2023-heatwave enrichment of extreme VPD-z. All three
  variables use a temporal day-of-year leave-one-year-out anomaly. Generated by
  `src/section11_anomalies.py`.
- `section14_results_note.md` — the secondary CSI threshold analysis, including segmented and
  change-point diagnostics, ET corroboration, and the data-adequacy caveats. Its headline sample
  is daytime `sample_label == "primary"` (`n_tree_valid >= 3`); night and pooled-overpass results
  are sensitivities. The primary RQ1 detector is instead the Section 15 two-dimensional
  `vpd_z` × `sm_z` response surface. **Verdict: no robust threshold detected**: Phoenix has only
  9 paired block groups (fewer than the 10 required for confirmatory inference). Produced by
  `notebooks/14_exploratory_threshold.ipynb` (logic in `src/section14_threshold.py`).
- `section14b_mixed_effects_note.md` — the pixel-level crossed mixed-effects and whole-BG cluster-
  bootstrap sensitivity. Its within-BG VPD/SM terms combine spatial and temporal variation; they
  are not labelled as purely temporal effects.
