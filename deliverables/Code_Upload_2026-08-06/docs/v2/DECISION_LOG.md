## Status meanings

- `FROZEN` — binding for runs that could expose the affected result.
- `PROVISIONAL` — chosen direction, awaiting stated verification; affected result runs are
  prohibited.
- `OPEN` — unresolved and must not be silently inferred from output.
- `SUPERSEDED` — retained for history; replacement ID is named.
