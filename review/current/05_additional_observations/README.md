1. Define the population and temporal target. Original and common populations give materially different magnitudes.
2. Specify a practically meaningful difference and acceptable uncertainty. The 0.10 K Stage 1 SE benchmark supplies neither a time-effect threshold nor a scale margin.
3. Audit repeated dates within the same month and time window, with comparable footprint and sensor conditions. Singleton June morning/afternoon and August afternoon groups need replication.
4. The recorded 2023 Phoenix audit found no July/September morning opportunity in the defined window. Any other-year scope must be explicit and maintain city/year/month comparisons.
5. Assess a consistent ECOSTRESS collection and canopy/context vintages before choosing new observations. Add a city only if it supplies a specific missing condition.
