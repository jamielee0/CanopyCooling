# Scope and model for Task 1

The main pilot contains eleven Phoenix and five Atlanta acquisitions from 2023. Temperature is primary. Emitted longwave flux and its fixed-reference temperature equivalent are paired diagnostics, and VPD is descriptive.

Each city/pass estimates one shared canopy slope on native ECOSTRESS cells, with 1 km block intercepts and six existing context controls: imperviousness, low vegetation, bare cover, buildings, elevation and distance to water. Canopy and context variables are centered within blocks. Native observations, weights and resampling match across temperature and energy outcomes. The pilot uses Collection 002, with the documented inherited view-angle exception.

The frozen original sixteen populations and linear baseline remain unchanged. Common footprint and quadratic models are labelled sensitivities. Prior thermal access and later disclosure are recorded. A formal practical scale margin remains unset. Seven separately processed other-year Phoenix passes have zero main-pilot weight and are outside this review's effect scope.
